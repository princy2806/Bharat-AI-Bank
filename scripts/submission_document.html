Problem Statement

🕐 Long Wait Times

Indian banking customers spend an average of 18–25 minutes waiting to speak to a human agent for basic queries like balance checks, dispute filing, or EMI modification requests.

🌐 Language Barrier

Over 70% of India's banking population prefers Hindi or regional languages, yet most bank chatbots operate only in English, creating a massive accessibility gap.

📄 Manual Document Processing

Credit card dispute filing requires customers to physically visit branches and submit paper receipts. Processing takes 5–7 working days with no automated receipt extraction.

📊 Complex EMI Restructuring

Customers facing financial hardship must visit branches multiple times to explore loan restructuring options. No instant simulation or transparent comparison is available.

Our Solution

Bharat AI Bank is a fully autonomous Agentforce-powered banking assistant that handles 5 core banking scenarios end-to-end, without any human agent involvement.

🏦

1. Real-Time Account Balance & Mini Statement

Customer asks in Hindi/English → Agent retrieves live savings, credit card, mutual fund and mortgage balances + last 5 transactions, formatted clearly with debit/credit indicators. Works via WhatsApp and Experience Cloud chat.

💳

2. AI-Powered Credit Card Dispute Filing

Customer reports unauthorized charge → Agent asks for receipt/bill → Customer uploads PDF → Einstein Document AI extracts Amount, Merchant, Date automatically → Dispute case created instantly with provisional credit applied within 24 hours. Supports pasted receipt text too.

📄

3. Document AI — Universal Receipt Extractor

Uses Salesforce Intelligent Document Processing (IDP) with a custom Credit_Card_Details configuration. Processes hotel bills, invoices, and credit card statements uploaded by customers. Extracts structured data (JSON) and passes it to downstream dispute/KYC workflows.

📊

4. EMI Restructuring Simulator

Customer in financial distress says "meri EMI reduce karo" → Agent calls EMI Simulator → Instantly returns 3 restructuring options (reduced tenure, extended tenure, moratorium) with exact EMI figures → Customer selects preferred option → RM callback scheduled automatically.

🌐

5. Multilingual Experience Cloud Portal

Custom branded banking dashboard LWC with animated hero, account cards, quick actions, and integrated AI agent floating button. Responds in the customer's language throughout the entire session — Hindi, English, or Hinglish.

Agent Topics Configuration

📊 Account Balance & Statement

Triggers on: balance, statement, kitna paisa, account info. Calls GetAccountBalance. Returns formatted Hindi/English response with all account types.

💳 Credit Card Dispute

3-step flow: ask for receipt → process Document AI → file dispute. Never auto-files from statement data. Handles text receipts and PDF uploads.

📄 Document Verification & KYC

Handles all file upload events. Routes to ProcessDocumentAIUniversal with Credit_Card_Details IDP configuration. Displays extracted fields.

🏠 Loan EMI Restructuring

Immediately calls EMI Simulator on any mention of EMI/loan hardship. Shows 3 options with exact figures. Schedules RM callback on selection.

📞 Escalation

Transfers to live human agent on explicit request. Falls back to logging a support case if escalation fails. Always maintains conversation context.

❓ General FAQ

Searches Knowledge Articles for policy questions. Never gives generic advice — always retrieves from official bank knowledge base.

Agentforce Differentiators

🧠 ReAct Reasoning

The agent uses Agentforce's ReAct planning engine to reason across multi-step banking flows — it knows to ask for a receipt BEFORE filing a dispute.

📄 Einstein Document AI

Native integration with Salesforce IDP using a custom Credit_Card_Details configuration that understands Indian banking receipts and hotel invoices.

Responds automatically in the customer's language — no language selection needed. Detects Hindi, English, and Hinglish seamlessly within the same session.
